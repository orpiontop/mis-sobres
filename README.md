# Mis sobres

App para repartir el dinero del mes en sobres y apuntar gastos desde el móvil.

- Se instala en el móvil y abre sin conexión.
- Guarda los movimientos en el dispositivo y los sube a una hoja de Google cuando hay señal.
- `google/Codigo.gs` es el script que se pega en la hoja (Extensiones → Apps Script).
